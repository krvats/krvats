equations until every step held up on its own, then used the same method
to find five new series for 1/π. Verified to 40+ decimal digits, written
up properly, and posted for anyone to check:

**[Reconstructing and Extending Ramanujan's 1914 Series for 1/π →](https://doi.org/10.5281/zenodo.22715269)**
